# 4. 找端口、烧录舵机 ID

```
1 备料 → 2 打印 → 3 装软件 → [4 烧 ID] → 5 组装 → 6 标定 → 7 动起来 → 8 示教
                              ^ 你在这里
```

**这一步要在组装之前做。** 舵机一旦装进结构里，再拆线重烧 ID 会很麻烦。

## 为什么舵机需要 ID

六个舵机共用一根线。Mac 发出"转到 90 度"的指令时，总线上每个舵机都会收到。每条指令前面带一个 ID，只有 ID 对上的那个舵机才执行。

所有舵机出厂 ID 都是 **1**。六个一起接上去，会一起响应，分不清谁是谁。所以要**一个一个单独接**，分别改成 1 到 6。ID 写在舵机的永久存储（EEPROM）里，只用做一次。

## 接线

驱动板上要认的三个接口：

- **USB-C 口**：接 Mac
- **DC 圆孔电源口**（黑色圆筒插座）：接电源
- **3-pin 插座**：接舵机（两个插座用哪个都行）

```
墙插 ── 12V 电源 ──桶形插头──> 驱动板 DC 口
Mac  ── USB-C 线 ───────────> 驱动板 USB-C 口
                              驱动板 3-pin ──> 一个舵机
```

**电源和 USB 都要插。** USB 只传数据不供电：只插 USB，舵机不响应；只插电源，Mac 看不见板子。板子上的灯亮了说明通电了。

如果你的 Waveshare 板子上有跳线帽，两个都要插到 **B（USB）** 一侧。

## 找端口

```bash
lerobot-find-port
```

**这个命令在干什么：** macOS 把每个串口设备都表示成 `/dev/` 下面的一个文件。列表很长，大部分跟机械臂无关：有系统自带的虚拟端口，还有**蓝牙设备**（我的耳机和音箱都在里面）。列表里没有任何一项写着"机械臂"。

所以这个工具拍两次快照：先记下所有端口，让你拔掉驱动板的 USB 线，再记一次，消失的那个就是你的板子。

**要在板子插着的时候运行**，提示拔线时真的把 USB 拔掉。你会得到类似这样的结果：

```
/dev/tty.usbmodem5B901506081
```

记下来，后面每条跟硬件打交道的命令都要用。为了少打字可以：

```bash
export SO101_PORT=/dev/tty.usbmodem5B901506081
```

**Mac 和 Linux 的区别：** Linux 上端口叫 `/dev/ttyACM0`，还要 `chmod` 或者加 `dialout` 用户组。macOS 两样都不用。

## 烧录 ID

```bash
lerobot-setup-motors \
    --robot.type=so101_follower \
    --robot.port=$SO101_PORT
```

脚本会一个一个提示你接哪个舵机。目前的版本是从夹爪（ID 6）开始，最后是底座 shoulder_pan（ID 1）。以脚本的提示为准，不要照搬网上看到的顺序：

1. **只接**它说的那一个舵机，总线上不能有别的。
2. 按回车，写入 ID。
3. 拔掉，换下一个。

每次按回车前都检查一下电源插头和 3-pin 线有没有插牢。换舵机时很容易把插头碰松，松了这颗就烧不上，而且不一定有明显提示。

**官方的小建议：** 每烧完一个舵机，就先插上一根 3-pin 线放一边，组装时线已经在上面了。

给每个舵机贴个标签写上关节名或 ID（美纹纸就行）。六个一模一样的黑盒子很容易混。
