# 8. 没有 leader 臂的示教回放

```
1 备料 → 2 打印 → 3 装软件 → 4 烧 ID → 5 组装 → 6 标定 → 7 动起来 → [8 示教]
                                                                     ^ 你在这里
```

## 思路

工业机械臂几十年来都是这么编程的。没人去敲"肘部 37 度"，而是用手把机器人摆到想要的姿势，存下来，摆下一个，再存。每个存下来的姿势叫一个**路径点**（waypoint）。回放时控制器在相邻路径点之间平滑过渡。

`teach.py` 就是给 SO-101 做的这件事。

## 关键机制：扭矩

舵机通电后默认**上力**（扭矩开），死死锁在当前位置，用手掰不动。示教时脚本把扭矩**关掉**，臂变软，你就能摆姿势。回放时再把扭矩**打开**。

**扭矩一关，臂会因为自重往下垂。** 开始录之前先用手扶住。

## 录制

```bash
python scripts/teach.py record pickup
```

摆好一个姿势按一次回车，存一个路径点。全部录完输入 `q` 回车。第一次可以录这样一套：

1. 起始姿势，臂收着，夹爪张开
2. 伸向桌面某处，夹爪还张着
3. 原地用手把夹爪合上
4. 抬起来
5. 转到另一边，夹爪张开
6. 回到起始姿势

动作存成 `scripts/moves/pickup.json`，里面是路径点列表，每个点记着六个关节的位置。

## 回放、循环、串联

```bash
python scripts/teach.py list                      # 看有哪些动作
python scripts/teach.py play pickup               # 播一次
python scripts/teach.py play pickup 5             # 播五遍
python scripts/teach.py chain home pickup wave home
```

`chain` 按顺序播放多套动作，中间自动平滑过渡。建议录一个 `home`（臂收拢、放低），串联时用它开头和结尾。

机械臂会先从当前位置移动到第一个路径点，按回车前先让开。

## 速度

```bash
python scripts/teach.py play pickup --speed 2
```

速度的原理：两个路径点之间，`glide()` 会发 `BASE_STEPS` 次小幅度的位置指令，每次间隔 `STEP_DELAY` 秒：

```
单段耗时 = BASE_STEPS × STEP_DELAY = 60 × 0.02 秒 = 1.2 秒   （速度 1 时）
```

每到一个路径点还会停 `PAUSE`（0.4 秒）。`--speed 2` 会把步数和停顿都减半。

想变快有两种办法，效果不一样：

- **减少步数**（`--speed` 用的就是这个）。舵机内部的控制器会把每一小步平滑掉，所以步数不太少的话动作依然顺滑。
- **缩短间隔。** 步数不变，但指令可能发得比舵机能跟上的还快，机械臂会落后于脚本。

怎么找上限：从 2 开始往上加。看到轨迹变成一段一段的折线，或者终端已经打印到"路径点 4"而机械臂还在往路径点 3 走，就到头了。我的经验是 **3 到 4** 是实用上限。STS3215 本身的最高转速是硬上限，指令发得再快也没用。

## 可调常量

在 `scripts/teach.py` 顶部：

```python
BASE_STEPS = 60    # 两个路径点之间切多少步
STEP_DELAY = 0.02  # 每步间隔多少秒
PAUSE = 0.4        # 每个路径点停多久
```

- 动作速度可以，就是点和点之间停太久：把 `PAUSE` 改成 0.1 或 0。
- 想要更丝滑、不在乎慢：把 `BASE_STEPS` 调到 100 以上。

## 安全关机

1. 停掉正在运行的脚本（`Ctrl + C`）。脚本断开连接时会关掉扭矩。
2. **用手把臂摆到收拢的低位姿势。** 断电瞬间舵机会完全失力，举高的臂会直接砸下来。
3. 先拔**电源**，再拔 USB。

先拔电源是因为 USB 不供电：电源一断舵机就停了，总线上不会留下发了一半的指令。

下次开机：插电源、插 USB、`conda activate lerobot`，直接跑脚本。舵机 ID 和标定都永久保存了，不用重做。
