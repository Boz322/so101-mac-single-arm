# 2. 用拓竹 P1S 打印零件

```
1 备料 → [2 打印] → 3 装软件 → 4 烧 ID → 5 组装 → 6 标定 → 7 动起来 → 8 示教
          ^ 你在这里
```

电子件还在路上的时候就可以开始打印。

## 参数在哪设

层高、填充这些参数不在打印机上设，也不在手机 Bambu Handy App 里设。手机 App 只能打印别人已经切好片的模型。你需要在 Mac 上用 **Bambu Studio**：

1. 安装 Bambu Studio 并登录，它会自动找到同一局域网里的 P1S。
2. 新建项目，机型选 P1S，耗材选 PLA（或 PLA+）。
3. 把 STL 文件拖进去。
4. 按下表改参数，切片，发送到打印机。

手机 App 还是有用的：可以看打印摄像头，打歪了能远程停。

## 我用的参数

| 参数 | 值 | Bambu Studio 里的位置 |
|---|---|---|
| 喷嘴 | 0.4 mm（P1S 默认，不用换） | |
| 层高 | 0.2 mm | 质量 |
| 稀疏填充密度 | 15% | 强度 |
| X-Y 孔洞补偿 | 0.05 mm（量规测试后定的，见下文） | 质量 |
| 支撑 | 按 STL 自带的摆放 | |
| 材料 | PLA+ 或拓竹 PLA Tough | |

为什么不用普通 PLA：底座、大臂、舵机座一直在受扭矩，普通 PLA 时间长了容易在螺丝孔附近变形或开裂。

## 先打量规

SO-ARM100 仓库的 [`STL/Gauges`](https://github.com/TheRobotStudio/SO-ARM100/tree/main/STL/Gauges) 里有校准量规。正式开打之前先打 `Gauge_0` 和 `Gauge_tight_1`，拿舵机试一下松紧（舵机还没到的话可以用乐高版本的量规）。

这一步是看你的打印机打出来的孔偏小还是偏大。我的 P1S 把 **X-Y 孔洞补偿设成 0.05 mm** 之后刚好合适，你的机器可能要别的值。在这里发现问题，比打完一整套零件才发现便宜得多。

## 用哪个 STL

P1S 的打印盘是 256 x 256 mm，一体化排版的文件都放得下。我用的是 [`STL/SO101/Follower/Ender_Follower_SO101.stl`](https://github.com/TheRobotStudio/SO-ARM100/tree/main/STL/SO101/Follower)（按 220 x 220 的盘排的），follower 的所有零件都在一个文件里，方向已经摆好。

**不要旋转零件。** 方向是按强度和最少支撑排好的。

## 打完之后

把支撑全部清干净，小一字螺丝刀最好用。舵机仓里残留的支撑，是之后舵机塞不进去、或者关节转起来咯吱响最常见的原因。
