# Examples

`calibration_example.json` is the calibration file from my arm, for reference only.
It shows what a healthy calibration looks like. **Do not use it on your arm**; run
`lerobot-calibrate` yourself. See [docs/en/06-calibration.md](../docs/en/06-calibration.md).

`calibration_example.json` 是我这条臂的标定文件，仅供参考，用来看正常的标定结果长什么样。
**不要直接用在你的臂上**，请自己跑 `lerobot-calibrate`。见 [docs/zh/06-calibration.md](../docs/zh/06-calibration.md)。
